# SNITS College App

An Android Application built with **Jetpack Compose** and **Firebase** (Authentication & Firestore) for SNITS College.

## Features
- **Student Portal**:
  - View personal daily attendance summary and attendance percentage.
  - Access college notes, timetable, assignments, and daily activity updates (Read-Only).
- **Teacher Panel**:
  - Batch Class Attendance Sheet to mark attendance for all registered students in 1 click.
  - Publish & manage notes, timetables, assignments, and daily activities.
  - Restricted User Registration: Register new students and teachers directly from the portal.
- **Security & Privacy**:
  - Role-based access control with Firebase Auth & Firestore Rules.

## Tech Stack
- Kotlin
- Jetpack Compose (Material3)
- Firebase Auth & Cloud Firestore
- Android Gradle Plugin (AGP) 9.x
